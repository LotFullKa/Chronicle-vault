# Нисс
## Описание

Высшая эльфийка, заражённая демоническим проклятием. [[Брат Аврелий]] вёз её к друидам в [[Эльфодрево]] для исцеления.

## История

### 2026-05-16

Направлена вместе с героями в [[Храм Вокин]] по велению Латандера.

### 2026-05-16

Убита [[Квилаттэ]] по приказу друидов Кормантора, которые застали группу врасплох. [[Квилаттэ]] убила её немедленно без колебаний, что шокировало всех.
