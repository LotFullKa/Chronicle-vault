# Храм Латандера
## Описание

- Небольшой храм у восточных стен [[Хилсфар]]а, обращён к рассвету.
- Розовый камень, окно на восток; на алтаре молот «Гнев Утра» (ассоциируется с [[Брат Аврелий]]).
- В FR-каноне крупных храмов Латандера в Хилсфаре нет; это локальный храм кампании.
- Учение местных утренников: «рассвет только для человечества» — **локальная ересь**, не ортодоксия Латандера.
- Отсюда родом [[Брат Аврелий]].

## История

Пока без отдельных сессий, кроме связей через Аврелия.
